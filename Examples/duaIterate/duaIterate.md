## Basic level understanding of how duaIterate generates the set of routes
1. Initialize link costs using free-flow travel times and compute the shortest path for each origin-destination (OD) pair.
2. Add the computed shortest paths to the route set associated with each OD pair.
3. Select a route for each traveler according to the corresponding route-choice probabilities.
4. Run the traffic simulation
5. Update link costs using travel times observed during the simulation.
6. Recompute shortest paths and add any newly discovered paths to the corresponding route sets.
7. Update route-choice probabilities (Gawron algorithm by default)
8. Repeat Steps 3–7 until convergence.

The set of routes for each OD pair is built incrementally during the assignment process as new shortest paths are discovered under the updated network conditions. The parameter `--max-alternatives` specifies the maximum number of routes that can be stored for each OD pair (5 by default).
