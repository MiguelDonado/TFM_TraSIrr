### FIFO violation explanation
1. This breach occurs when a vehicle that departs later arrives sooner. 
  - Example: If a vehicle starts at the end of interval 1, it will take 10 min, but if it starts at one moment later, it will take 8 min.
2. When transportation people talk about FIFO, they assume every link is FIFO. 
  - If every link is FIFO, a route is FIFO. If a link is non-FIFO, the route may or may not be FIFO.
3. When creating the avg link travel time table, we are using discretized intervals. The time discretization can create artifical FIFO violations even if underlying simulation is perfectly FIFO.
4. The fact that Rgap computation seems to work, suggest that violations are probably mild, and TDSP is producing approximately correctly shortest paths.
