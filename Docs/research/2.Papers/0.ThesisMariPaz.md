

# Dynamic network models

They represent dynamic traffic behavior (interactions between travel decisions, traffic flows, travel time and travel cost)

## DTA (Dynamic traffic assignment)

Framework to model how traffic evolves over time. It considers time and space. It seeks to describe the assignment of the demand on different paths which connect every OD pair in a state of equilibrium. 

It has two components:

1. Dynamic network loading

   - Can be solved analytically (3 different approaches)
   - By simulation. Use a traffic simulator to reproduce the complex traffic dynamics. The problems are mathematically formulated (like optimization), but some traffic dynamics constraints very hard to express with equations (flow conversation, traffic propagation...) so they are solved simulating traffic evolution.

2. Flow reassignment

   The traffic assignment process is determined by a hypothesis of how travelers use the routes. A traffic model needs an assumption about behavior. This assumption defines how flows are assigned. If a DTA model assumes DUE, then the traffic assignment is performed so that resulting flows satisfy DUE condition (no one uses a suboptimal route). Then the model assign flows until no one can improve travel time. Traffic assignment following this kind of rule are called user equilibrium models.

#### DSO (Dynamic system optimum) 

One of the behavioral hypothesis that DTA can follow to assign flows.

#### **DUE (Dynamic User Equilibrium)** 

Behavioral foundation for describing the dynamic traffic state. It is a time-dependent generalization of Wardrop (DUE). It can be solved:

1. **Analytically** (mathematical optimization)
2. Using **simulation** (approximate heuristic solutions at a reasonable computational cost)

When travel time of all vehicles within an interval of time are equal and minimal, the network is in DUE state. It must hold for every OD pair and every departure time. 

Travel times change over time -> Decisions depend on departure time -> Equilibrium is time-dependent
